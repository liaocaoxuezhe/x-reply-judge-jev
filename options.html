X Reply Judge (Jev)

Shows a TypeSafe Jev probability that feed posts and replies are AI-written. Only the text is sent to the API.

Stored only in chrome.storage.local on this device. Create one at console.typesafe.ai.

Detection prompt

Edit the rules sent to the model. Chinese and English are supported. Click Save to apply. Saving a changed prompt clears old scores; reload X to scan again.

Scanning

Comments with 10 or fewer non-whitespace characters show a fixed 20% without calling the model or using the auto-scan quota. Manual scan always stays available (floating button + toolbar icon), even in Auto mode.
Advanced: API endpoint (defaults match the TypeSafe docs) A host other than api.typesafe.ai requires granting an optional host permission (asked on Test connection).

Based on x-reply-guard (MIT).
